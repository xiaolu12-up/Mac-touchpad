### 🌟 重点内容：你现在可以
- **像 macOS 一样跟手的动态三指拖移**：重构非对称 EMA 速度包络（快攻慢释）与三段式类 macOS 动态增益曲线，慢速微调精准到逐字字符选词，高速挥动顺滑跨屏移动。
- **杜绝静止跳动与横移纵向漂移**：引入三指分轴中值+一致性均值滤波与宽高比各向同性补偿，拖动静止、微停顿或抬手离板瞬间指针稳如磐石，横向拖移不再有手腕微弧偏漂。
- **光标默认速度更符合直觉**：出厂默认光标速度调整为 70，加速度调整为 10，更加契合主流高分辨率屏幕与日常拖拽移动手感。
- **沉浸式无边框视窗与窗口随手拖拽**：去除非客户区原生粗边框，顶部整个标题栏支持平滑拖拽移动与双击最大化/还原。
- **卡片式更新日志模态框（深浅双主题自适应）**：精巧卡片式设计，深色与浅色模式无缝自适应切换，分类特性胶囊徽章（`[新增]` / `[改进]` / `[修复]`）与详情链接一览无余。
- **10 种主流语言深度国际化**：支持自动跟随 Windows 操作系统语言，亦可随时手动自由切换（简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Русский、Português），全界面组件与手势动作实时翻译。
- **现代化 Git CI/CD 流程**：支持推送主分支自动打包构建测试工件、推送 Release Tag 自动发版，并支持 Workflow Dispatch 手动选择构建参数。

### 📝 深度详解与改动

#### 🚀 核心触控引擎优化 (Core Engine)
1. **三段式动态加速度曲线 (Dynamic Velocity Curve)**
   摒弃原有单调 Sigmoid 曲线，构建了涵盖「低速精细微调区（0.48x~0.52x）」、「中速自然跟随区（0.75x~1.50x）」与「高速跨屏渐进加速区（2.6x+）」的动态加速度模型。
2. **多指分轴中值滤波与手腕微弧纠偏**
   三指并排移动时独立计算 X/Y 轴中值与一致性均值，剔除单指黏滑侧滚造成的纵向干扰，在偏角小于 16.7° 时平滑过滤手腕自然摆动产生的垂直漂移。
3. **静止迟滞死区与急停回弹拦截 (Anti-Recoil)**
   静止时清空亚像素余数锁定光标，起步时采用软拐点平滑释放；急停瞬间自动拦截因指腹皮肤弹性回弹产生的反向位移。

#### 🎨 视觉与交互重构 (UI & UX)
1. **沉浸式无边框窗体设计**
   移除 Windows 原生边框与标题栏，结合 Windows 原生 Win32 消息泵实现顺滑的窗体拖拽和双击窗口最大化。
2. **卡片式更新动态模态框**
   支持通过顶部标题栏、侧边栏或关于页面随时呼出更新日志，在浅色与深色主题间平滑过渡。
3. **10 语种全局翻译**
   内置全套多语言字典，支持自动感知 Windows 语言并允许用户在系统设置中即选即切。
