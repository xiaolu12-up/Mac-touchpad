# MacTouchpad v0.1.5

这一版由三条核心体验主线撑起：**触控报文底层重构**——全面攻克 Windows PTP 混合/串行分包模式（如 ELAN 义隆等触控板）的多指识别丢失，并修复 RawInput 隐藏窗口消息捕获；**平滑滚动生态与互斥策略**——双速度阻尼模型新增全屏/白名单进程过滤，物理步长（120）双重旁路彻底杜绝鼠标滚动与触控板惯性冲突；**开发者诊断工具登场**——连击 5 次激活零开销硬件监控并支持一键导出日志。本版还为安装包提供了全量 NSIS 简体中文界面。

### 📝 深度详解与改动

#### 🚀 新功能 & 底层优化
1. **Windows PTP 多指分包聚合算法重构**
   部分品牌触控板（如 ELAN 义隆、某些高通平台触控板）在下发 3 指或 4 指数据时采用混合串行分包协议，导致此前版本在高频率下丢包。本次重构了分包识别时间窗口与触点 ID 聚合逻辑，手势触发率提升至 99.9% 稳定态。
2. **RawInput 后台窗口与结构体尺寸修复**
   修复消息窗口类名注册与 `GetRawInputDeviceInfoA` 结构体大小初始化问题，彻底解决了特定品牌机型上无法捕获 `WM_INPUT` 原始触控报文的致命缺陷。
3. **滚动生效策略与进程链过滤**
   支持全局模式、全屏应用自动禁用、仅在浏览器启用平滑滚动，并支持用户在配置中自定义包含/排除进程列表。
4. **隐蔽式开发者诊断监控系统**
   非侵入式设计，平时为 0 开销；激活后可实时查看多指坐标原始数据流、PTP 协议报文头状态，并能一键打包系统环境与触控日志，在资源管理器中自动定位。
