# MacTouchpad v0.1.8

这一版聚焦三指拖移与内置更新流程的稳定性：三指拖移支持抬起后续拖和单指接管，更新检查与下载改为后台执行，并优先下载推荐安装包。

---

### 🌟 重点内容

- **三指拖移更稳定**：优化释放后重新开始、触点抖动与静止保持逻辑，避免拖移过程中被误释放或误触发点击。
- **单指接管继续拖动**：三指拖移后，剩余单指移动可接管当前拖动，适合边缘抬指后的连续操作。
- **更新流程不再阻塞界面**：更新检查与安装包下载改为后台任务执行，界面保持可交互。
- **优先下载推荐安装包**：更新时优先选择 `_x64-setup.exe`，无可用 EXE 时再回退到 MSI。

---

### 🛠 修复内容

1. **释放后重新开始**
   抬指后在释放窗口内重新按下的触点会继续当前拖动，无需重新越过启动阈值。

2. **误触发点击 / 双击**
   关闭「释放后重新开始」时，拖移中的短暂触点丢失不会释放鼠标按键，避免 Windows 将按下/抬起识别为点击或双击打开文件。

3. **两指与单指续拖**
   两指可保持拖移状态；剩余单指移动超过防抖阈值后接管拖动，抬指前的微小抖动不会误接管。

4. **拖移期间边缘手势抑制**
   拖动按住期间不再触发单指边缘滑动，避免误调音量或亮度。

5. **更新检查与下载**
   Gitee / GitHub 更新源并行检查，增加连接与总超时；下载支持重试、安装包大小校验和残留文件清理。
   更新报告按远端 Release 版本渲染，不再错误显示本地兜底版本。
