# MacTouchpad v0.1.6

这一版重点聚焦于**性能与交互底层的极致精简**：**鼠标钩子性能大幅优化**——移除全局鼠标钩子中冗余的触摸事件重复过滤逻辑，显著降低高轮询率鼠标下的 CPU 占用与输入延迟；**平滑滚动与触控板旁路互斥加固**——彻底解决外接鼠标滚轮平滑滚动与笔记本触控板原生滑动的互斥竞争；**硬件诊断交互打磨**——优化关于页面「硬件监控诊断」触发灵敏度与视觉反馈。

### 📝 深度详解与改动

#### 🚀 性能优化 (Performance)
1. **全局鼠标钩子性能瘦身**
   针对 Windows 低级鼠标钩子 (`WH_MOUSE_LL`) 进行了调用链瘦身，移除了多余的触摸事件判定分支，保证在 1000Hz+ 高回报率电竞鼠标或快速滑动时保持极低 CPU 开销。
2. **触控板与滚轮物理时序去重**
   结合触控板时效窗口判定，进一步优化平滑滚动与触控板触控动作的边界隔离。

#### 🐛 交互打磨 (Improvements)
1. **开发者诊断面板触发优化**
   微调了「关于」页面连击检测的时序算法，防止快速连续双击被系统判定丢失。
